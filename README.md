# ANN Iris Classification From Scratch

## Project Overview
This project implements an Artificial Neural Network (ANN) from scratch using NumPy for multiclass classification on the Iris dataset.

## Dataset
- Iris Dataset
- 150 samples
- 4 features
- 3 classes

## Network Architecture
- Input Layer: 4 neurons
- Hidden Layer 1: 8 neurons (Sigmoid)
- Hidden Layer 2: 6 neurons (Sigmoid)
- Output Layer: 3 neurons (Softmax)

## Libraries Used
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Results
- Test Accuracy: 100%
- Sigmoid Accuracy: 100%
- Tanh Accuracy: 95.65%

## How to Run
1. Install required libraries.
2. Open the notebook.
3. Run all cells sequentially.
4. View generated outputs and visualizations.
